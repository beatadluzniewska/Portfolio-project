About me

I am a UX Designer with an architectural background, currently expanding my role into software development. I have professional experience working on complex, system-oriented products in an aerospace environment and recently completed a postgraduate program in Programming and Databases.

My work sits at the intersection of user experience and engineering. I design with a strong focus on structure, usability, and system constraints, and I enjoy implementing solutions that connect frontend interfaces with backend logic and data.

I work with JavaScript, React, HTML, CSS, and I am developing my skills in backend development and relational databases. I am interested in both UX-focused and development-focused roles, particularly within technical, system-oriented products.

Help Desk Portal (Internal Product)

UX design for a mission-critical internal Helpdesk portal used daily by Boeing employees. I led a comprehensive UX/UI assessment of the existing Enterprise Helpdesk system in close collaboration with multiple teams, aligning requirements, constraints, and custom technical features before design began. The final solution supports complex support flows, dynamic content, permissions, and analytics within a highly structured internal platform.

Stack: Figma · HTML · CSS · JavaScript · JavaScript APIs · Internal Platform Backend · Photoshop

NoteBox – Task & Work Tracking Application

A full stack web application designed to manage task lists and tasks with priorities, deadlines, and progress tracking. I implemented the backend using Java and Spring Boot with a relational database, and built a responsive frontend in React, focusing on clear data structures, CRUD operations, and usability. The project was developed iteratively, starting from an MVP and expanded with search, filtering, sorting, and progress visualization features.

Stack: Java · Spring Boot · Spring Data JPA · PostgreSQL · React · REST API · Docker · HTML · CSS

React.js weather project

A responsive weather application built with React and vanilla JavaScript, integrating the OpenWeatherMap API. It supports city search, real-time weather data, unit conversion without reload, and extended five-day forecasting in the React version.
